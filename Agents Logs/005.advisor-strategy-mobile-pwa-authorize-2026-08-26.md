## Challenged assumption (plan + technical 006)

**Assumption:** Precache shell (`/`, CSS/JS, icons) in Đợt 0 is safe if `/api/*` is excluded; Add to Home Screen follows from manifest + icons; close-on-navigate is the drawer bug; bump `CACHE_NAME` in Đợt 5; hide bottom-nav on iOS keyboard in Đợt 3.

**Counter:**

1. **Installability ≠ manifest file.** SW today never registers unless Notification is `granted`. A2HS/beforeinstallprompt will `NOT_MEASURED`/fail for the default user. Wave 0 must `register('/sw.js')` on app init **independent of push permission**; keep `pushManager.subscribe` gated.
2. **Pages does not use Hono for `/sw.js`.** `_routes.json` sends only `/api/*` to the Worker. Manifest/icons/SW must land in **`dist/`** via `copy-public.mjs` **and** `preview-watch.mjs`. A new `app.get('/manifest.webmanifest')` without copy scripts = prod 404.
3. **Precache `index.html` + `app.js` in `install` is an architecture risk**, not a comfort feature. Cache-first on a 1.3 MiB SPA + deferred CACHE_NAME bump (plan Đợt 5) **sticks users on old finance/task UI** — that violates `money_ssot` *visibility* even without touching `finance.ts`. Wave 0: **no** precache of HTML/JS; fetch handler must **bypass `/api/*`**; optional cache-first **only** icons/manifest; bump `CACHE_NAME` to `bim-sw-v2` **now** because a `fetch` listener is new.
4. **Hamburger cannot be “closed” until it can open.** Phone CSS has no `translateX(0)` override. Wave 0 needs `.sidebar.mobile-open` + scrim — do **not** reuse desktop `.collapsed` (inverted).
5. **iOS ignores manifest icons** for Home Screen historically → `apple-touch-icon` (180/192) in Wave 0, not only 512 in Đợt 5.
6. **Bottom nav vs keyboard:** deferring `visualViewport` hide to Đợt 3 means Wave 0 tabs cover inputs on every form. Wave 0 includes a **minimal** hide when visual viewport height drops (not chat rewrite).
