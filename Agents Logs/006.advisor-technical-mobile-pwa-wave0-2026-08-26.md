## Risk register

| Risk | Mitigation | Wave |
|------|------------|------|
| `navigate()` close drawer breaks `#/project-detail` hash restore | Close only when `innerWidth<768` and sidebar open; test hashchange + `restorePageFromHash` | w0 |
| Bottom nav vs iOS keyboard | Defer hide-on-keyboard to w3 (`visualViewport`); w0 tab bar static | w0/w3 |
| SW precache stale assets | Bump `CACHE_NAME` (e.g. `bim-sw-v2`); activate + clients.claim; document hard-refresh in QA | w0, w5 |
| Precache accidentally includes API | Explicit allowlist URLs only in install handler | w0 |
| Icon PNG >50MiB or base64 in markdown | PNG ≤512KB each; git size check; evidence records bytes+SHA only | w0, w5 |
| Role wrong bottom tab (Finance vs PMO) | Reuse existing `admin-only` / role visibility classes from sidebar | w0 |
| Desktop regression from global mobile CSS | All shell/nav rules inside `@media (max-width:767px)` | w0–w5 |
