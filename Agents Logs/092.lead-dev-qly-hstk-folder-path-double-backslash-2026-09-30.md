# lead-dev — QLy HSTK folder path double backslash

**Symptom:** Explorer `Windows can't find 'C:\\Users\\...'` — literal doubled `\` in `bimfolder:open?path=`.

**Root cause:** `design-hstk.js` inline `onclick` embedded path via `.replace(/\\/g, '\\\\')` then `designOpenFolder(path)` rebuilt the URL with `bimfolderLink(path)` instead of using the anchor `href` (already `encodeURIComponent` once). Doubled `\` in the argument → `%5C%5C` in query. No collapse in `bimfolder.ps1` / `normalizeNasPath`.

**Fix:** `normalizeWindowsPath` / `Normalize-PathSafe` on save, link, scan, open; `designOpenFolder(event)` uses `getAttribute('href')` only; server `normalizeNasPath` collapses `\\+`.

**Deploy:** `public/static/design-hstk.js` → `dist/static/`; cache `v=20260930o`; `tools/bimfolder/bimfolder.ps1` → `C:\Onecad\bimfolder\`.

**Verify:** `vitest run src/design.test.ts`; PS trace OK single path to explorer.
