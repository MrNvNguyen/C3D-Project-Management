## Problem (product)

Dark mode (`html[data-theme="dark"]`): **same table, mixed rows** — some rows/cells stayed light (`#fff`, `#fff5f5`, `#fafafa`, Tailwind `bg-red-50` / leave zebra) while text used shell light colors → illegible wash. Screenshots: dashboard overdue table, project tasks, `#/tasks`, leave list, legal checklist, analytics task detail + finance project grid, cost-types thead.

**Verified root cause:** `.overdue-row { background: #fff5f5 !important }` (light-only, beats generic `.bg-white` dark override). Plus `#leaveTable tbody tr.leave-row-even/odd` hardcoded white. Plus JS inline `style="background:#…"` on analytics/legal/finance rows and cells.

---

## Changes

### `public/index.html`

- Dark **`.overdue-row`** translucent red tint + overdue date text (`text-red-600` → `#fca5a5`).
- Dark overrides for **`bg-red-50` / `bg-pink-50` / `bg-blue-50` / `bg-*-100`** status washes.
- **Inline background neutralization** on `table tbody tr` / finance `td` for common light hex values.
- Semantic row classes: **`an-row-*`**, **`legal-tr-*`** with dark counterparts.
- **Default `tbody tr` background** on `.card table.w-full` → `--shell-surface`.
- **Leave:** `#leaveTable` thead/zebra/hover/pagination; leave action button colors; page-leave card header gradient override.
- **Legal:** `#legalStagesContainer` stage/table chrome + inline dark text fixes.
- **Cost types:** `#page-cost-types` thead/body explicit shell table tokens (thead was too dark / low contrast).

### `public/static/app.js` (minimal)

- Analytics task detail rows: replaced inline `background:#fff5f5|#f9fafb` with classes `an-row-over|an-row-warn|an-row-zebra`.
- Legal checklist rows: replaced inline `trBg` with `legal-tr-done|legal-tr-child|legal-tr-default`.

**Not touched:** `app.v2.js`, `finance.ts`, migrations, executive-dashboard.js (no reported regressions there in this pass).
