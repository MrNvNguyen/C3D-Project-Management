Chuẩn bị local (chạy một lần)

  1. npm install
  2. npm run db:migrate:local — áp migration D1 local
  3. npm run db:seed — dữ liệu mẫu (tùy chọn)
  4. npm run preview:watch — build + D1 local + auto reload khi đổi code
  5. Nếu login fail: npm run db:seed:test
  6. Mở trang này: /preview

Một lần (không watch): npm run preview:local. Dev HMR: npm run dev.

Checklist thủ công (trước commit)

  • npm test — vitest PASS (Layer A)
  • Đăng nhập app chính, mở 1 dự án, xem tab Tài chính — số đồng khớp API
  • Member không truy cập được route admin/finance (403)
  • Timesheet: 2 dự án cùng ngày lưu được, không ghi đè
  • Migration mới đã db:migrate:local và sẵn sàng apply prod
